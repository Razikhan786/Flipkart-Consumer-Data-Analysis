# 🛒 Flipkart Consumer Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing Flipkart consumer and order data using Python. The main objective is to clean the dataset, perform Exploratory Data Analysis (EDA), identify customer purchasing patterns, and generate meaningful business insights through data visualization.

## 🎯 Project Objectives
- Clean and preprocess the dataset using Pandas and NumPy.
- Handle missing values and duplicate records.
- Analyze customer purchasing behaviour.
- Identify top-performing product categories.
- Analyze payment methods and delivery performance.
- Visualize sales trends and business patterns.
- Generate actionable business insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset Information
- Dataset: Flipkart Consumer Dataset
- Total Records: 12,014
- Total Columns: 29
- File: `flipkart_cleaned_data.csv`

The dataset contains customer, product, order, payment, shipping, delivery, rating, and transaction-related information.

## 🧹 Data Cleaning
The dataset preparation and cleaning workflow included:
- Checking missing values.
- Handling missing data.
- Identifying and removing duplicate records.
- Standardizing inconsistent values.
- Checking data types.
- Preparing the cleaned dataset for analysis.

## 📊 Exploratory Data Analysis (EDA)
The following analyses were performed:

1. Customer and City Analysis
2. Age Group Analysis
3. Gender Analysis
4. Product Category Analysis
5. Payment Method Analysis
6. Order Status Analysis
7. Delivery Performance Analysis
8. Monthly Revenue Analysis

## 💡 Key Business Insights
- Mumbai has the highest number of order records in the dataset.
- Fashion is the most frequently ordered product category.
- Mobiles generate the highest recorded category revenue.
- Most order records are marked as Delivered.
- Monthly revenue fluctuates over the analyzed period.
- Shipping modes show differences in average delivery time.
